# Triple Espresso

## Project structure

- `index.html` is the site entry point.
- `styles/` contains the CSS stylesheets.
- `images/` contains the logo, background, favicon, and café image.

## Nombre del proyecto

-Cafe Triple expreso

## Descripcion del proyecto

- ESte preoyecto es una landingpage de una cafeteria, se se pueden hacer reservaciones de en la cafeterai seleccionando fecha y hora, la informacion se envia para poder hacer la reservacion. utilizo formularios, imagenes, varios estilos utilizando html y archivos css.

## Planes de mejora

- Se prevee crear el envio automatico de las reservas al correoelectronico y al propio ERP Y CRM de la empresa
- En una version posterior se va agregar el menu del cafe con la posibilidad de preordenar.
